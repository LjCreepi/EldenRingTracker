# Changelog

All notable changes to this project are documented here. Newest first. Each
released version has its own file under [`changelog/`](changelog/).

> **The canonical changelog is `../CHANGELOG.md` at the repo root.** This copy
> tracks changes while working inside `projekt/`; fold its notes into the root
> file **before** cutting a release. A dated, versioned release is cut only on
> explicit request (see `CONTEXT.md` → "Versioning").

## Releases

- [0.6.0](changelog/0.6.0.md) — 2026-09-11 — Weapon Attack Rating, Wondrous
  Physick, and automatic Golden Seed / Sacred Tear tracking with a Flask
  Used count.
- [0.5.5](changelog/0.5.5.md) — 2026-09-11 — fix a stale completion label in
  the docked marker detail panel on tablet/desktop; internal dead-code,
  duplication and template-complexity cleanup (`fallow`).
- [0.5.4](changelog/0.5.4.md) — 2026-09-11 — fix overlapping status chips,
  clipped map-layer and class-hint text on narrow viewports, a German update
  dialog, and several undiscoverable UI cues (inventory tap target, bonus-step
  flag, hidden marker categories).
- [0.5.3](changelog/0.5.3.md) — 2026-09-11 — fix the docked side menu getting
  stuck hidden on phones after collapsing it in landscape and rotating back;
  the store listing's remaining screenshots are filled in.
- [0.5.2](changelog/0.5.2.md) — 2026-09-11 — fix unlabelled map pins,
  blocked pinch-zoom, and an invalid menu ARIA structure; full accessibility
  score on both Lighthouse presets.
- [0.5.1](changelog/0.5.1.md) — 2026-09-10 — fix the "What's New" note rendering
  as a clipped box; catch the store listing up to 0.5.0.
- [0.5.0](changelog/0.5.0.md) — 2026-09-10 — multiple characters (create, name,
  switch, delete), class locked at creation, an onboarding wizard, and the
  Equipment screen flags items you don't own.
- [0.4.0](changelog/0.4.0.md) — 2026-09-10 — Character menu: a by-hand Inventory,
  an Equipment loadout from a ~1,900-item catalog, and a Status sheet.
- [0.3.0](changelog/0.3.0.md) — 2026-09-04 — collapsible side menu, and a first
  pass at a genuinely different tablet/desktop layout.
- [0.2.0](changelog/0.2.0.md) — 2026-09-04 — dungeons, merchants and ten
  collectible categories on the map, with imagery from the Elden Ring Fan API.
- [0.1.1](changelog/0.1.1.md) — 2026-09-04 — fix marker clustering crashing in
  production builds.
- [0.1.0](changelog/0.1.0.md) — 2026-09-03 — first release: interactive map,
  per-character progress tracking, offline support.
