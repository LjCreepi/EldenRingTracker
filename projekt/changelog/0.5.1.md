# 0.5.1 — 2026-09-10

### Fixed

- **The "What's New" note rendered as a tiny box with one clipped line and a
  stray scrollbar.** The inline `<ion-modal>` drops `WhatsNewComponent`'s host
  straight into the modal frame, and an inline host collapses `ion-content` to
  zero height. Fixed with `:host { display: flex; flex-direction: column;
  height: 100% }` plus explicit `--width` / `--height` / `--border-radius` on the
  modal so it's a compact centred card (≈ 420 px on desktop, 92 vw on phones)
  rather than Ionic's default full-screen sheet.
