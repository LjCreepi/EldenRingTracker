# 0.5.2 — 2026-09-11

### Fixed

- **Screen readers announced every map pin as a bare "button".** Leaflet
  renders each marker as `role="button"` with no accessible name; pins are now
  labelled with the marker's name (set on the icon's `add` event, so it
  survives Leaflet recreating the icon on decluster).
- **The page couldn't be pinch-zoomed.** The viewport meta tag disabled it
  (`user-scalable=no`, `maximum-scale=1.0`) — an Ionic starter default.
  Removed; the map still owns its own pinch/scroll zoom independently.
- **The side menu's ARIA list structure was invalid** — the "Hide" button
  lived inside the list's header, and collapsible group headers
  (*Golden Seeds & Sacred Tears*, …) used `role="button"`, both illegal
  children of a `role="list"`. The header now sits outside the list, and
  group headers are real `<ion-item button>` rows instead of a
  `role`-hacked `<ion-item-divider>` — which also gets them native
  Enter/Space activation and `aria-expanded` for free.

Found via a Lighthouse accessibility audit. Accessibility now scores 100/100
on both the mobile and desktop presets (was 90/87).
