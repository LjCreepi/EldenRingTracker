# 0.2.0 — 2026-09-04

### Added

- **Dungeons and Merchants on the map.** ~40 minor dungeons (catacombs, caves,
  tunnels, hero's graves), placed at their interior Site of Grace; ~20 wandering
  merchants. Merchants are a two-part tick: *found* (the completion) and then
  *Bell Bearing claimed* (a bonus step that isn't counted — a found merchant
  with no bell bearing shows a small flag on its pin).
- **Ten collectible categories** from Elden Ring's own item-placement data:
  Golden Seeds, Sacred Tears, Larval Tears, Memory Stones, Talisman Pouches,
  Crystal Tears, Whetblades, Bell Bearings, Cookbooks, Gloveworts. Only
  guaranteed pickups; DLC-only locations are skipped (no DLC tiles yet).
- **Menu groups.** Categories can sit under a labelled section (*Golden Seeds &
  Sacred Tears*, *Upgrade Materials*, *Consumables & Kit*). Groups are visual
  only — each category still toggles on its own.
- **Default-hidden categories.** The ten collectible categories start switched
  off; turn on the ones you care about. Preferences now records explicit on and
  off choices (`shownCategories` / `hiddenCategories`).

- **Marker imagery from the Elden Ring Fan API.** `npm run fetch:images` (manual,
  online, output committed) pulls an authentic in-game icon for each collectible
  category and a screenshot for ~120 boss markers, each downscaled with `sharp`
  (icons 128 px, boss shots 500 px — ~1.5 MB committed in total). Boss images
  show in the marker detail popover; collectible icons replace the grey
  placeholder on the map and in the popover. Bell Bearings use a hand-placed
  `src/assets/markers/bell-bearings.png` — the Fan API has no bell-bearing item.

### Changed

- `marker-catalog.json` schema: new `groups`, and `group` / `defaultHidden` /
  `bonusStep` / per-marker `image` on a category / marker. See
  [docs/adr/0003](docs/adr/0003-marker-catalog-schema-v2.md).
- `scripts/prepare-map-assets.mjs` now also reads `placements.ts` + `goods.ts`
  (vendored into `tempAssets/compass-data/`) and folds in `fetch:images` output.

### Fixed

- CI test run failed on `node:26` — its inert experimental `localStorage` global
  shadows jsdom's, so every spec's `localStorage.clear()` threw. `test-setup.ts`
  now swaps in a working Storage when it detects this.
