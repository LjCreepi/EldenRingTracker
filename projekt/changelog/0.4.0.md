# 0.4.0 — 2026-09-10

### Added

- **Character menu** — three new screens styled after Elden Ring's own menus,
  each a side-menu entry:
  - **Inventory** — a by-hand mirror of what the active Character holds. Every
    item has a quantity you set; the ＋ on a row bumps it, the toolbar's
    **Add items** opens a catalog browser with a "hide items I already hold"
    filter. Tabs follow the game's inventory categories.
  - **Equipment** — the three-column layout: slot grid (armaments ×6, armour ×4,
    talismans ×4, arrows/bolts, spirit ash, great rune, an Ash of War per
    armament, a memorised-spell list), the selected item's stats in the middle,
    and a live Character Status panel. The equip picker defaults to your
    inventory with a toggle for the whole catalog; anything equipped that you
    don't hold is flagged.
  - **Status** — the editable sheet: pick one of the 10 starting classes, raise
    the eight attributes, see Level and the derived stats. Equip Load % and roll
    weight are exact; HP/FP/stamina and the rest are **approximations** and the
    screen says so (docs/adr/0005). Weapon Attack Rating is not simulated.
- **Item Catalog** — `scripts/fetch-item-catalog.mjs` (manual, online, output
  committed — like `fetch:images`) builds `src/assets/data/item-catalog.json`
  (~1,900 items) and 64 px icons under `src/assets/items/<resource>/` from the
  Elden Ring Fan API. `ItemCatalogService` loads it at runtime. Base game only.
  See docs/adr/0004.
- **Item icons warm into the cache on launch** (`ItemAssetCacheService`), shown
  as a small corner chip — once per catalog version, then the Character screens
  render from cache and work offline. Same mechanism as the map tile warm-up.
- **Settings → Reset** now has three buttons, each scoped to the active
  Character: *Reset map progress*, *Reset inventory & character sheet*,
  *Reset everything*.
- The Character screens restructure their columns into a stacked layout on
  narrow viewports, behind a single flag (`COMPACT_CHARACTER_LAYOUT` in
  `core/layout/compact-layout.ts`) so it can be reverted in one edit.

### Changed

- The **Add items** sheet pages its list behind an infinite-scroll (40 rows at a
  time) instead of rendering all ~1,900 at once — the button no longer lags.

### Fixed

- **The page itself no longer zooms** on double-tap, two-finger pinch, or
  Ctrl+wheel — only the map zooms. Needed per-gesture guards since no single
  setting covers every browser (iOS Safari ignores `user-scalable=no`).

### Docs

- `CONTEXT.md` — new glossary section (Item, Item Catalog, Item Asset Cache,
  Inventory, Loadout, Character Sheet, Attribute, Derived Stat, Class, Great
  Rune); the **Character** term now owns the inventory, loadout and sheet as well
  as its completions.
- README shows the new tabs (`docs/images/character-menu-inventory.png`).
- `docs/adr/0004` — item catalog from the Fan API, with our own slug ids.
- `docs/adr/0005` — character stats are approximated; Attack Rating is a stub.
- `README.md` — a "Planned, not yet built" section (weapon upgrade + affinity +
  real AR, crafting, gestures data, save-file import, DLC, …).
