# 0.5.3 — 2026-09-11

### Fixed

- **The docked side menu could get stuck permanently hidden on phones.** The
  CSS that hides the menu when a user collapses the docked layout
  (`.menu-collapsed .split-pane-side`) targeted a class Ionic assigns once and
  never removes, instead of Ionic's own `.split-pane-visible` (which tracks
  the `when="md"` breakpoint live). A phone wide enough in landscape to dock
  the menu, collapsed there, then rotated back to portrait, was left with the
  now-overlay menu forced to `display: none` — unreachable from the hamburger
  button, with no way back in. The rule now also requires
  `.split-pane-visible`, so the hide only applies while actually docked.
