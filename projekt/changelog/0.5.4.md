# 0.5.4 — 2026-09-11

### Fixed

- **Two "preparing" status chips (map tiles, item art) could land exactly on
  top of each other on the Map page, unreadable.** Both are `position: fixed`
  to the same corner; `PreparingChipComponent` now takes a `stackIndex` so the
  map-tile chip stacks above the item-art one whenever both are visible.
- **The map layer switch ("Lands Between" / "Underground") clipped to
  unreadable fragments** ("LANDS BET…", "UNDERGR…") — in the map toolbar at
  landscape-phone/small-tablet widths (~768–900px, where it's the *only* way
  to switch layers, since the side menu's own copy is hidden there), and
  separately in the side menu's copy on phones. Widened the toolbar switch's
  max-width and tightened the menu segment's padding/font-size so both full
  labels fit either way.
- **The "— a safe pick if you're unsure" hint on class selection clipped to
  "…"** at narrow widths — Ionic's radio label doesn't wrap by default. It now
  sits on its own wrapping line.
- **The service-worker update prompt was a German browser `confirm()`** — the
  only non-English string and the only native dialog anywhere in the app.
  Replaced with an `AlertController` alert in English, matching every other
  confirmation in the app.
- **Inventory rows gave no visual cue that tapping the name opens the item's
  detail pane.** `detail="false"` suppressed Ionic's default chevron with
  nothing put back in its place; restored it, matching the side menu's
  character-bar row.
- **The Bonus Step flag on a completed marker (e.g. a found merchant's
  uncollected Bell Bearing) was an unlabeled amber dot, explained nowhere in
  the app.** It's now an actual flag glyph (the CSS class was already called
  `__flag`), explained on the About page under a new "Map symbols" section,
  and folded into the marker's screen-reader label.
- **Dismissing a "preparing" chip didn't say it leaves the download
  running** — that was only in the screen-reader-only `aria-label`. Added a
  visible "Hiding this won't stop it" line under the progress readout.
- **New players had no way to learn that most marker categories start
  switched off** (10 of 14, including Golden Seeds and Crystal Tears) —
  nothing on the map or in the menu said so. Added a line to the onboarding
  intro and a hint under the side menu's "Markers" header.

Found during a manual pass across desktop, mobile-portrait and
mobile-landscape viewports, alongside a UI-instructiveness review.
