# 0.3.0 — 2026-09-04

### Added

- **Collapsible menu groups** — the group dividers in the side menu toggle their
  category rows open/closed; the collapsed state is remembered
  (`collapsedGroups` preference).
- **"All markers" toggle** at the top of the Markers menu — flips every marker
  category on or off the map at once; reads as on only when they all are.
- **Collapse the side menu** on tablet / desktop — a "Hide" button in the menu
  header hides the docked menu so the map gets the full width; a matching button
  appears in each page's toolbar (where the hamburger sits) to bring it back in
  one click. Choice is remembered (`menuDocked` preference).
- **Guide text on the first-run map-preparing screen** — a short "what is this
  app" intro, plus an explicit note that choosing "Continue now" does **not**
  stop the tile download: it keeps saving the map in the background so offline
  access still ends up working.
- **App-store listing** — `store/listing.md` (draft; kept in sync with
  user-facing changes, see `CONTEXT.md` → Versioning).
- **Responsive layout now visibly differs, not just resizes** (docs/responsive.md):
  - The Surface / Underground layer switch moves into the map page's own
    toolbar on tablet+/desktop; phones keep it in the side menu.
  - Marker detail opens as a **docked side panel** on tablet+/desktop instead
    of a floating popover; phones keep the popover.
  - An overall completion card ("Tarnished's progress: done / total") appears
    on the map, tablet+/desktop only.

### Changed

- **Web app manifest** completed — `id`, `description`, `lang`, `dir`,
  `orientation`, `theme_color` / `background_color`, `categories`. The browser /
  PWA chrome colour now follows the active colour scheme (`<meta name="theme-color">`
  kept in sync by `ThemeService`).
- **Side-menu breakpoint pinned** — `ion-split-pane when="md"`: overlay menu on
  phones (portrait and landscape), docked from tablet-portrait up. Tested
  viewports written up in `docs/responsive.md`.
- `prepare:map` now writes `marker-catalog.json` / `map-tiles-index.json` only
  when the generated data actually changed, and the catalog `version` is a
  content hash instead of a per-run date stamp — no more spurious diffs after
  `npm start`.
- CI `test_app` job runs `npm run lint` alongside the unit tests.
- Removed the unused Capacitor scaffold (`capacitor.config.ts`, the
  `ionic.config.json` integration) — the app is browser-PWA only.
- **Offline tile warm-up no longer stops on "Continue now"** — dismissing the
  preparing screen/chip only hides it; the download (both the surface and
  Underground tile pyramids) now always runs to completion and the cached
  version is always recorded, so offline access is no longer conditional on
  waiting out the full download.
- `anyComponentStyle` budget raised `2kb → 4kb` warning / `4kb → 8kb` error —
  the app-shell components (`AppComponent`, `MapPreparingComponent`) legitimately
  carry more layout CSS than a typical page.

### Fixed

- Removed a duplicated `<link rel="manifest">` from `index.html`.
- **Marker-detail popover no longer resizes/repositions itself when you mark
  something done or undo it** — the mid-interaction jump was the popover
  reacting to its own content changing size. It now just closes on the action
  instead (tap the marker again for the new state); the docked panel variant
  isn't affected since it never moves.

### Docs

- README marker counts refreshed (~740 markers across 14 categories); PWA-only
  note added; links to `docs/responsive.md` and the store listing.
- Boss-image match coverage (86 / 112) is recorded in `scripts/README.md` and
  regenerated by `npm run fetch:images`; `matchBoss` gained a guarded
  token-overlap fallback (was 84/112 before it).
- `ADR 0002` notes `sharp`'s native-binary install cost in CI.
- Removed a duplicate agent-skills tree (`.agents/`); `.claude/` documented as
  assistant configuration, not app code.
