# 0.5.0 — 2026-09-10

### Added

- **Character creation & switching.** A character now has a **name** and a
  **starting class**, both chosen when it's created. The character bar at the top
  of the side menu opens a **Characters** screen — switch the active one, create
  more, or delete one (type its name to confirm; the cascade clears that
  character's map progress, inventory, loadout and sheet).
- **Onboarding Wizard.** First run shows a short app intro, then character
  creation (class picker with each class's level + stat spread, Vagabond
  pre-selected as "a safe pick if you're unsure", name prefilled "Tarnished").
  Skippable — Skip takes the default Vagabond named "Tarnished". Re-openable from
  **About → "Show the intro again"**. When the last character is deleted it
  reappears at the creation step alone, with no skip.
- **"What's New" note** after an app update — hand-written player-facing
  highlights per version (`core/onboarding/release-notes.ts`), shown once. The
  developer changelog under `changelog/` is separate.
- **The mirror.** The Furled Finger's Trick-Mirror talisman icon beside the name
  on the **Status** screen renames the character — an *Elden Ring* nod (Fia's
  room at the Roundtable Hold), and the only way to rename one. The rename prompt
  shows the censored name as placeholder, never the raw one.
- **Name filter.** Names are capped at 16 characters and shown through a small,
  deliberately partial censor — "Knight" displays as "K\*\*\*ht" everywhere,
  though it's still stored and usable as typed (docs/adr/0007). `censorName()`
  lives in `src/app/features/character/name.ts`.

### Changed

- **Class is locked at creation** (docs/adr/0006). The Status screen's class
  picker is gone; class + level now show as a read-only identity header, and
  "reset character sheet" resets attributes to *that character's* class base.
  `classId` moves from the Character Sheet onto the Character; existing saves
  migrate on load (class copied from the old sheet, or Vagabond).
- The app shell is mounted from the first frame, with the Onboarding Wizard as a
  full-screen overlay while there's no active character — so the router outlet
  keeps its page and the map is ready the moment the wizard closes.
- The first-run map download is no longer a blocking splash — it's the same
  dismissible corner chip used for later updates, and the app is usable as soon
  as a character exists. `MapPreparingComponent` removed in favour of the shared
  `PreparingChipComponent`.

### Fixed

- **The Equipment screen now marks equipped items you don't own.** Each item in
  the loadout that isn't in the Character's Inventory carries a warning marker —
  a corner icon on the slot tile, an amber Ash-of-War button, a "not in
  inventory" note on memorised spells, and a banner in the detail column.
  Previously only the equip picker flagged them; the loadout view itself did not.

### Docs

- `docs/adr/0006` — class locked at character creation.
